## Usage

``` r
acro_summarise(.data, ..., .groups = NULL, .by = NULL)
```

## Arguments

- .data:

  A data frame or a data frame extension

- ...:

  Name-value pairs of summary functions. The name will be the name of
  the variable in the result

- .groups:

  Grouping structure of the result

- .by:

  Optionally, a selection of columns to group by for just this
  operation, functioning as an alternative to group_by()

## Value

Summary of the data
